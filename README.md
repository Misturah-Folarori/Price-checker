
# 🏷️ Price Checker

## 💡 What It Does
**Price Checker** helps users find and compare prices of everyday products in real time.  
Instead of moving from store to store, users can check one platform to see which shop offers the best deal nearby.  

## 💭 Why It Matters
Prices change often — from groceries to fuel — and many people waste time or money because they can’t easily compare.  
Price Checker solves this by providing **up-to-date, community-driven price data**, helping users make smart buying decisions.

## 👥 Who It’s For
- Everyday shoppers who want to save money  
- Students and families comparing grocery or household prices  
- Drivers tracking fuel price changes across stations  
- Vendors wanting to stay aware of market trends  

## ✨ Key Features
- 🔍 Search for any product and see current prices across stores  
- 🕒 View last updated time for each price  
- 📍 Find the cheapest store near you  
- 🧾 Submit or update a product’s price with proof (optional photo/receipt)  
- 📊 See price trends or recent changes  

## 🧰 Technologies (Planned)
- **Frontend:** React / Next.js  
- **Backend:** Node.js (Express)  
- **Database:** MongoDB  
- **APIs:** Google Maps API for location + internal Price Data API  
- **Hosting:** Vercel (Frontend) & Render / Railway (Backend)
